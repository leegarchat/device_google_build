## 12.3 — 20/10/2026

> Для обычных пользователей: рут-менеджер ставится сам без сбоев,
> форматирование Data в рекавери починено, два новых аддона PEP.
> Обновление поверх 12.3 без вайпа.

- **Установка reSukiSU починена — работает 100%**: установщик теперь
  работает в контексте ядра KSU, стартует на каждой загрузке без
  SELinux-запретов. Чистая установка, обновление со старой версии
  и защита от даунгрейда — все проверено на устройстве. Намеренное
  удаление пользователем по-прежнему уважается.
- **OrangeFox: починка форматирования Data** — теперь работает как
  задумано и не тянет багов в дальнейшей работе.
- Исходники синхронизированы с последними EvolutionX (включая новый
  апдейтер и выключенный Face Unlock).
- **PEP: новый аддон RAM Purge** — одна кнопка, сбрасывающая всю фоновую
  активность (`kill-all`). Рут не нужен: PEP работает как system и уже
  имеет разрешение. Замерено на Pixel 8: свободно 319 → 1700 МБ,
  холодный старт карт 2.8 → 1.3 с. Нажимать, когда телефон задыхается
  после долгого аптайма, — не в цикле, одного нажатия достаточно.
- **PEP: новый аддон Yandex Maps Fast** (для пользователей СНГ) —
  Vulkan-рендер вместо заблокированного OpenGL (тайлы грузятся на ~10 с
  быстрее), лента свернута по умолчанию, кнопка такси убрана из карточек
  мест, поиск открывается на вкладке История. По умолчанию включен только
  Vulkan, остальное — опциональные тумблеры.

## 12.3 — 15/10/2026

> Для обычных пользователей: октябрьская безопасность, рут-менеджер ставится
> сам, зум шторки починен, переводы полные. Обновление поверх 12.2 без вайпа.

- База на свежем сорсе EvolutionX. Октябрьский патч Android.
  Vendor и boot патчи без изменений.
- Ядро: WildKSU релиз 20 → 21. Менеджер: reSukiSU RC1 → RC3.
- Рекавери: OrangeFox обновлён до R12 — база исходников A16.
- **Автоустановка менеджера reSukiSU** (только KSU-сборки):
  APK едет внутри образа инертным файлом и ставится один раз как
  обычное приложение после первой загрузки / первой загрузки после
  обновления. Системная настройка помнит версию: та же → пропуск,
  новее на устройстве → оставить (без даунгрейда), старее или нет →
  поставить / обновить. Ошибка = повтор на следующей загрузке.
  Удаление пользователем уважается — переустановки нет.
- **PEP: новый движок LSPlant** (был Pine):
  - Свой нативный бэкенд вместо старых бинарников Pine — быстрее и чище.
  - Движок хуков стартует за миллисекунды вместо секунд.
  - Уживается с другими хук-инструментами: если один уже внедрён, PEP
    использует его вместо двойного инжекта.
  - Старые настройки работают — читаются автоматически, новые сохраняются
    в новом формате.
  - Бан на приложение уважается: заблокированное остаётся без хуков после ребута.
  - Safe mode при инжекте: битое состояние гасит хуки вместо краша.
- **PEP: зум шторки переделан** (SystemUI хуки 2.2.22):
  - Зум от нуля: плюс углубляет сжатие, минус разворачивает к увеличению.
  - Работает даже при блюре 0. Без рывка на входе, без мигания на краях.
  - Одинаково плавно на 60 и 120 Гц.
  - Дата в шторке снова открывает Календарь; цвета иконок AOD вернулись.
- **PEP: обновление аддонов по воздуху** — все встроенные модули пересобраны,
  манифесты версий + файлы, проверка обновлений внутри менеджера.
- **PEP: переводы полные** — весь набор строк на всех языках.
- **PEP: патчи освежены** под октябрьское дерево (часть старых апстрим
  впитал — выведены).
