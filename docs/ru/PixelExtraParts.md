# PixelExtraParts — гид пользователя

[English](../en/PixelExtraParts.md) | **Русский**

Одно приложение — **Pixel Extra Parts** — держит допы прошивки.
Без рута. Без лишних модулей. Просто работает.

Где искать:

- Дравер → **Pixel Extra Parts**
- Настройки → пункт **Pixel Extra Parts**
- Плитки быстрых настроек — долгое нажатие открывает страницу

<details>
<summary>📱 Главный экран</summary>

Поиск сверху. Группы: **System**, **Misc**, **SystemUI**, **Camera**.
Плавающая кнопка: добавить плитку, рестарт лаунчера / SystemUI, ребут.

<details>
<summary>🎨 Насыщенность — сила цвета</summary>

Делает цвета бледнее или сочнее. Применяется сразу, с превью на фото.

- **Своя насыщенность** — главная. Выкл = обычно.
- **Уровень — 0–200%, норма 100%.**
- **Плитка** — быстро вкл / выкл из шторки.

Системный цветовой режим перебил — просто примените заново.

<details>
<summary>☀️ Буст на солнце</summary>

Максимум яркости на ярком свете, потом возврат к вашей.
Два режима, только один за раз: **Авто** (по датчику) и **Постоянный** (всегда максимум).

- **Блокировка яркости** — держит максимум, блокирует слайдер.
- **Живая карточка** — текущий свет, прогресс до порога, температура чипа.
- **Порог света — 100 до 60 000 люкс.** Выше = включиться.
- **Задержки вкл / выкл — 0 до 10 сек.** Игнорирует тени.
- **Плавный рост — вкл/выкл + 100 мс до 5 сек.**
- **Опрос датчика — 30 мс до 10 сек.**
- **Страховки: лимит времени 10 сек до 33 мин, остывание после, лимит чипа 30–80°.**
  Пересидка или перегрев гасят с тостом, потом восстанавливают.

Живое уведомление с кнопками Выключить + Блок. Плитки: **AutoHBM**, **HBM**.

## Нагрев — сразу, без перезагрузки

Переключается **за секунды на живом телефоне**.
Старые экраны могут предлагать ребут — просто жмите ОК, уже работает.

<details>
<summary>🌡 Общий + на игру + очередь</summary>

- **Общий профиль** — по умолчанию для всего. Сток + связки Батарея / Процессор
  (Мягкий +5°, Средний +9°, Жёсткий +15°, Выкл = экстрим).
- **На приложение** — свой на игру, иначе общий.
  Телефон смотрит открытое приложение каждую секунду и меняет сам.
- **Очередь плитки (до 5)** — тап по плитке крутит любимые.
- Красные карточки = горячие режимы. Короткие сессии.

## Модули

<details>
<summary>🧩 Список модулей</summary>

- **Встроенные** (из прошивки) + **ваши** `.jar`.
- У каждого: вкл / выкл, где работает, свои настройки и страницы,
  импорт / экспорт, проверка обновлений, удалить.
- **Где работает** — Дефолт / Свои / Объединить + выбор приложений.
- Защита: повторы крашей ставят модули на паузу.
- **Плитки модулей** — свои тумблеры в шторке. Долгое нажатие открывает страницу.

## Плитки

Насыщенность, солнце-буст, постоянный буст, автоблок,
двойной тап, анимации, скролл, нагрев — крутит очередь,
зарядка, лупа, логи, хаб, плитки модулей.
Долгое нажатие на любую → её страница.

## Быстрые фиксы

<details>
<summary>Тумблеры не работают (иконки, лаунчер)</summary>
В сборке нет системной части. Патчи + пересборка чинят.
</details>

<details>
<summary>Лаунчер сломался после сетки / иконок</summary>
Плавающая кнопка → Restart Launcher.
</details>

<details>
<summary>Шторка не та</summary>
Мастер шторки выкл — сток вернётся сразу.
</details>

<details>
<summary>Буст сам гаснет</summary>
Страховка: лимит времени или температура с остыванием.
</details>

<details>
<summary>Модули пропали / safe mode</summary>
Три краша SystemUI за 3 минуты ставят модули на паузу.
Выключите подозрительный, выйдите из safe mode.
</details>
