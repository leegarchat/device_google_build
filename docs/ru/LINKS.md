<details>
<summary>Drive пишет quota exceeded?</summary>

- Откройте общую папку, спуститесь по дереву к устройству / версии
  (например Husky → A17 → 2026.09.05 → file.zip).
- Правый клик (или три точки) → **Make a copy** — склонирует на ваш Drive.
- Качайте клон со своего Drive. Там квоты нет.

</details>
